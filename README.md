# Φ Pattern Atlas

**Follow the evidence. Discover the connections.**

Open-source, evidence-first research atlas. Interactive visual investigations with explicit sources, relationship types, competing hypotheses, and uncertainty labels.

The initial case examines documented correspondence about OpenCog, Novamente, and Southern Trust Company. A research connection is not evidence of wrongdoing, and the platform distinguishes documented facts from allegations, proposals, and open questions.

The React application and full contributor documentation are coming through the first implementation pull request.
